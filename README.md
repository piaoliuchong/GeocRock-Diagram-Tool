## K2O-SiO2 图解工具代码简介

## 概述
`K2O-SiO2.py` 是一个基于 PySide6 和 Matplotlib 的岩石地球化学判别图解桌面工具，用于自动将样品划分为高钾、中钾、低钾三类。

## 核心功能
- **自动分类**：内置多边形边界算法，自动识别样品钾系列类别
- **数据加载**：支持 Excel 文件读取与智能列匹配
- **样式定制**：可自定义标题、图例、标记颜色/形状等，实时预览
- **配置持久化**：设置自动保存至 `k2o_config.json`，重启后恢复
- **结果导出**：支持分类结果表格查看及高分辨率图片导出

## 技术栈
PySide6（GUI）、Matplotlib（绘图）、Pandas（数据处理）、NumPy（几何计算）

## 主要模块
- **ConfigManager**：负责配置的加载、保存与重置
- **K2OSiO2Window**：主窗口类，集成界面布局、动态编辑系统与绘图核心逻辑
- **ResultTableDialog**：分类结果弹窗展示组件
- **point_in_polygon**：射线法点-多边形位置判断辅助函数

## 使用流程
打开 Excel → 选择数据列 → 自动投点分类 → 按需调整样式 → 导出图片或结果表
